# 极夜将启 · Frostlight

冰雪女王音乐可视化 — 放一首歌，看极光流动、冰晶绽放、霜冻蔓延、暖光破夜。

👉 **https://yuyaning-engineer.github.io/frost-viz/**

- **▶ 播放示例曲** — 原创纯器乐《极光余温》
- **📁 我的音乐** — 上传你自己的歌（想要《Let It Go》就传你的原声），画面实时跟随
- **🎙 麦克风** — 平板放音响旁即可跟随环境音乐
- 面板 **QUEEN** 可切换女王造型：❄ 睥睨 / ✦ 回眸
- 右上 **✦ 原理** 有滑块，能直接手动驱动场景

Three.js + Web Audio API，纯前端。姊妹项目：[B612 小王子可视化](https://yuyaning-engineer.github.io/b612-viz/)
